# Installing BroadLink IR Remote Mapper

Follow the maintained [installation and configuration guide](README.md#install).

Copy the repository's **`custom_components/broadlink_ir_mapper`** directory into
`config/custom_components/broadlink_ir_mapper`, or extract the release archive
there. This documentation directory is not an installable integration.

For existing installations, follow [upgrading and rollback](README.md#upgrading-and-rollback).
