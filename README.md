Home Assistant Apps

## HA+ Matter Hub

Install the maintained HA+ Matter Hub integration from its own custom repository
in Home Assistant 2026.11 or newer. Existing installations of the Supervisor app
can keep their Matter pairings by following the migration guide before changing
distributions. [Integration installation and migration](https://github.com/zvikarp/ha-plus-matter-hub/blob/main/docs/Getting%20Started/Installation.md)

The Supervisor app listed by this repository retains the 1.2.0 container.
[Legacy app documentation](./ha-plus-matter-hub/DOCS.md)

## HA+ IR Mapper

[HA+ IR Mapper](https://github.com/zvikarp/ha-plus-ir-mapper) is maintained in its
own repository, including guided IR learning, the HA+ sidebar/dashboard card,
HACS metadata, tests, and releases. Add that repository to HACS as an Integration.
Existing users can follow the [migration guide](https://github.com/zvikarp/ha-plus-ir-mapper#moving-from-the-ha-plus-repository).

## RGB Light Button Card

[Install the dashboard card](./rgb-light-button-card/INSTALLATION.md) to control
RGB lights with color presets, brightness, and supported effects.
